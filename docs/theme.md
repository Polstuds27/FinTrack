# FinTrack Design — Color Palette

Apply this palette in Phase 5 (sync) frontend work. Centralize it in `web/tailwind.config.js` under `theme.extend.colors` and use semantic class names.

| Role | Color | Hex |
|---|---|---|
| Primary | Deep Emerald | `#0F766E` |
| Primary Hover | Dark Emerald | `#0D5F59` |
| Accent | Mint | `#2DD4BF` |
| Background | Off White | `#F8FAFC` |
| Surface / Cards | White | `#FFFFFF` |
| Primary Text | Slate 900 | `#0F172A` |
| Secondary Text | Slate 500 | `#64748B` |
| Borders | Slate 200 | `#E2E8F0` |
| Income / Positive | Green | `#16A34A` |
| Expense / Negative | Red | `#DC2626` |
| Warning | Amber | `#D97706` |
| Info | Blue | `#2563EB` |

Current pages use default Tailwind `blue-600` accents and `gray-*` neutrals — migrate them to this palette during Phase 5.
